# mbuas-paczka

Paczka modow dla graczy serwera Minecraft **mbuas.pl** (Minecraft Java 1.21.1, NeoForge).

**Pobierz najnowsza paczke:** [Releases -> latest](https://github.com/mbuasm/mbuas-paczka/releases/latest) (plik `mbuas-<data>.mrpack`).

## Jak wejsc na serwer

1. Podaj swoj nick wlascicielowi serwera - obowiazuje whitelist.
2. Zainstaluj launcher z obsluga paczek Modrinth: [Modrinth App](https://modrinth.com/app) albo
   [Prism Launcher](https://prismlauncher.org/).
3. Pobierz plik `.mrpack` z linku wyzej i zaimportuj: Modrinth App -> `+` -> *From file*;
   Prism -> *Add Instance* -> *Import*. Launcher sam pobierze NeoForge i mody (ok. 80 plikow).
   Zalecane 6 GB RAM dla gry (ustawienia instancji).
4. Uruchom instancje, *Multiplayer* -> *Add Server* -> adres **`mbuas.pl`** (bez portu).
5. Konto premium wchodzi bez hasla. Bez konta premium przy pierwszym wejsciu ustaw haslo:
   `/register <haslo> <haslo>`, potem przy kazdym wejsciu `/login <haslo>`.

Gdy przy wejsciu pojawia sie "Incompatible mods" albo "Error loading mods" - masz stara paczke;
pobierz i zaimportuj najnowsza.
